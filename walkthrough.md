## What We Accomplished

### 1. Project Setup
We established the professional project structure you outlined:
- `data/`: Contains raw and processed datasets.
- `scripts/`: Modular Python code for data generation, preprocessing, and model training.
- `models/`: Where your trained models are saved.
- `reports/`: Stores your generated visualizations.

### 2. Data Collection (Synthetic Generation)
Since we focused on getting the ML pipeline running quickly, we built a script (`scripts/generate_sample_dataset.py`) to generate 1,000 synthetic records of browser extension behavior. 
- **Normal Behavior:** Low permissions, low network activity.
- **Suspicious Drift:** Sudden spikes in permissions and network requests.

### 3. Preprocessing 
We wrote `scripts/preprocess.py` to:
- Load the raw data.
- Encode categorical labels.
- Standardize the numerical features (`Permissions_Count`, `Network_Requests`, `Cookie_Access`, `API_Calls`) using `StandardScaler` so our machine learning model can learn effectively.

### 4. Anomaly Detection Model (Isolation Forest)
We built and trained an **Isolation Forest** model in `scripts/train_model.py`. 
- **Why Isolation Forest?** It is an excellent, simple unsupervised algorithm that isolates anomalies rather than profiling normal points. It perfectly fits your goal of starting simple before moving to LSTMs in Semester 8.
- **Results:** The model achieved **98.3% accuracy** and an F1-Score of 0.91 on detecting the suspicious behavioral drift.
