# Chapter 2: Literature Review

## 2.1 The Threat Landscape of Browser Extensions
The browser extension ecosystem, primarily dominated by the Google Chrome Web Store and Mozilla Add-ons, has grown exponentially over the last decade. Extensions improve usability by offering features like ad-blocking, password management, and productivity enhancements. However, this centralized distribution model has become a lucrative target for cybercriminals. Existing literature categorizes extension-based threats into two main types: initially malicious extensions (uploaded by attackers using fake accounts) and supply-chain attacks (legitimate extensions compromised later). While platforms like Google rely on automated code scanners and manual reviews to filter out the first category, the second category remains a significant blind spot.

## 2.2 Malicious Ownership Transactions
A major emerging threat in extension security is the "malicious ownership transaction." In this scenario, a benign developer with a highly-rated extension and a large user base is approached by a third party offering to buy the extension. Once the transaction is complete, the new owner pushes an update containing malicious payloads. Because the extension has an established trust score and the malicious code is often obfuscated or fetched dynamically from external servers post-installation, traditional platform security checks often fail to flag the update. Users unknowingly receive the malicious update, leading to data exfiltration, unauthorized cryptocurrency mining, or adware injection. 

## 2.3 Limitations of Static Analysis
Historically, detecting malware in extensions has relied heavily on static analysis—examining the source code (HTML, JavaScript, manifest files) for known malicious signatures or suspicious API calls before the extension runs. Several academic frameworks have proposed advanced static analysis tools to vet extensions in the Web Store. However, studies show that static analysis is increasingly ineffective against modern obfuscation techniques. Attackers often hide their logic or delay the execution of malicious code until the extension is safely installed in the user's browser, bypassing static checks entirely. 

## 2.4 The Shift to Behavioral and Temporal Analysis
To overcome the limitations of static analysis, recent cybersecurity research has pivoted towards dynamic and behavioral analysis. Dynamic analysis involves running the extension in a sandboxed environment to observe its actions. While effective, it is resource-intensive and attackers can sometimes detect the sandbox environment and suppress malicious behavior.

The concept of "Behavioral Drift" offers a more robust solution. By continuously monitoring the behavior of an extension over time in the wild (e.g., tracking the frequency of network requests, the domains accessed, and changes in requested permissions), security systems can establish a baseline of "normal" behavior for each specific extension. When an ownership transaction occurs and the new owner attempts to exploit the extension, the resulting actions will inherently deviate from this established baseline. This project builds upon this concept by utilizing unsupervised machine learning, specifically Isolation Forest, to model this temporal behavior and accurately identify the precise moment an extension drifts from benign utility to a malicious threat.
