# FYP Viva Preparation Notes

This document contains all the key explanations and analogies we discussed during our chat. You can use these notes to prepare for your Semester 7 Viva presentation!

## 1. What makes this project unique?
- **Supply Chain Attacks:** Traditional security focuses on malware. We focus on "Trust Betrayal"—when a safe extension is sold to a malicious buyer.
- **Behavioral Drift:** Instead of scanning hidden code, we monitor behavior over time. If an extension suddenly spikes in network requests, we catch it.
- **Zero-Day Threats:** Because our Isolation Forest learns what "normal" is, it can catch brand new, never-before-seen threats without needing a traditional virus signature.

## 2. Are the graphs real or fake?
- They are 100% real mathematical graphs generated by our Isolation Forest model analyzing the 1,000-record training dataset.
- In Semester 7, they are a static "snapshot" to prove the AI works.
- In Semester 8, when connected to a live database, these graphs will update dynamically as real extensions are monitored.

## 3. What is "Behavioral Drift" on the scatter plot?
- The bottom-left is the "Safe Zone" (low permissions, low network requests).
- If an extension is hijacked, its stats spike. On the graph, you see its dot jump from the bottom-left to the top-right and turn red. That exact jump is "Behavioral Drift."

## 4. How does the "Live Test" work without waiting for weeks?
- **Semester 7 (Isolation Forest):** The AI compares the live test against a *Global Baseline* of 1,000 extensions. If you input 5,000 network requests, it instantly knows it's an anomaly without needing history.
- **Semester 8 (LSTM):** Will track the specific history of an individual extension over weeks to detect subtle changes.

## 5. Why do we need "Test Live" if we have an automated Companion Extension?
- **Before You Install:** Allows users to manually audit an extension *before* installing it.
- **Immediate Suspicion:** If a browser is slow right now, the user doesn't want to wait a week for the next automated scan.
- **Viva Proof of Concept:** It acts as a "Demo Mode" so you can instantly prove to the panel that the AI works without waiting 3 weeks.

## 6. What happens the moment a user hits "Enter" in the Live Test? (Semester 8)
- **Instant Result:** The AI instantly scans the stats and says "Safe" or "Suspicious" today.
- **Registration:** It automatically adds the extension to the database so the Companion Extension can track it for the next 3 weeks to ensure it stays safe.

## 7. How will a user actually use this dashboard?
- Think of it like an **Antivirus Scanner for Extensions**.
- An IT Admin or user suspects an extension is bad. They open the dashboard, type in its stats, and the AI instantly flags it as safe or tells them to uninstall it.

## 8. Is this a Private or Global Dashboard?
- **Global Goal:** Our ultimate goal is a universal platform (like VirusTotal) with personalized "User Dashboards" where users can log in and see alerts for their specific extensions. The current dashboard is a prototype of that global system.
