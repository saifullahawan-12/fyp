A better Semester 7 order would be:

Learn the basics
Install tools
Collect data
Preprocess data
Build a simple anomaly detection model
Show outputs and graphs
Write report chapters
Prepare viva answers

For the model, do not start with complicated things like LSTM immediately.

Start with something simple like:

Isolation Forest
Random Forest
One-Class SVM

Then in Semester 8, you can say:

“We first developed a simple working anomaly detection model, then later improved it with temporal modeling and deeper ML approaches.”

That sounds very professional in viva because it shows gradual improvement.
